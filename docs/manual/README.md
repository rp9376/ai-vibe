## What is this, in one paragraph

An AI agent is a program that reads your code, edits files and runs commands to finish a task you describe in plain language. That's powerful and a bit dangerous, so here the agent runs inside **the bubble**: a locked-down container that can only see the project you opened, can't reach your files, passwords or network, and can only talk to an allowlist of websites. You stay in charge: you review what it did and decide what to keep.
